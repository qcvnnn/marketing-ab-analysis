# Кратко о методе

- **Конверсия:** пользователи с покупкой / все пользователи группы.
- **Абсолютная разница:** конверсия рекламы минус конверсия PSA, в процентных пунктах.
- **Относительное различие:** абсолютная разница / конверсия PSA.
- **Статистика:** двусторонний z-тест двух долей, интервал Newcombe–Wilson.
- **A/A-симуляция:** проверка частоты ложных отклонений на искусственных одинаковых группах.
- **Повторная загрузка:** идентификация файла по SHA256, защита строк первичным ключом, транзакция на партию.

Основные предпосылки сравнения — независимые наблюдения и корректное назначение групп. Количество и время показов используются описательно. Для оценки прибыльности нужны данные о затратах и марже.
